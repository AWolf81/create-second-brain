Welcome to your vault. Everything here is private — the site is served behind
HTTP basic auth and is not indexed.

## Start here

- [[05-knowledge/README|Knowledge]] — durable, transferable notes
- `04-projects/` — one folder per project, for orientation rather than planning

## How this works

Write markdown in `05-knowledge/`. Each note opens with a single `# Heading`,
and the build derives the page title, graph label and search entry from it —
nothing needs to be added to a note.

The panel showing nodes and edges is the link graph. It gets useful once notes
cross-link; with a handful of notes it is decorative.

Push to `main` and the site rebuilds.
